AI Programming Foundations: Titanic Data Workflow¶

Author: AI Foundations (Edward Hickman)
Dataset: Titanic (Seaborn example-data version)

This project builds a reproducible descriptive workflow for Titanic passenger records. It audits and cleans the data, explores recorded survival patterns across passenger groups, and communicates findings through three visualizations. No machine-learning models are trained.

Research question: How do recorded survival rates vary across passenger class and sex, and what does age missingness imply for interpreting the age distribution?

The local CSV contains 891 observations and 15 columns, exceeding the rubric's 200-row/five-column minimum. These records are not a complete census of everyone aboard the ship. Formal methodological citations and extended reasoning belong in the separate written report; the source snapshot is documented below.

4. Reusable cleaning functions¶

We define and apply three cleaning/transformation functions, each with a docstring. Column and text normalization make the workflow reusable, even though this well-structured source already has normalized names and observed labels.

For the research question, we select eight original fields and add an explicit age-missing flag. We preserve missing ages rather than invent age observations. Only Figure 1 excludes missing ages; Figures 2 and 3 use all 891 rows. Missing embarkation labels become unknown, not the most frequent port. This label does not recover the true port or remove potential missing-data bias.

In [4]:
def standardize_columns(frame):
    """Return a copy with trimmed, lowercase, underscore-separated column names."""
    result = frame.copy(deep=True)
    result.columns = (
        result.columns.str.strip().str.lower()
        .str.replace(r"\s+", "_", regex=True)
    )
    if result.columns.duplicated().any():
        raise ValueError("Column normalization produced duplicate names.")
    return result


def clean_categories(frame):
    """Normalize string labels and explicitly label missing embarkation as unknown."""
    result = frame.copy(deep=True)
    for column in result.columns:
        if pd.api.types.is_string_dtype(result[column]):
            result[column] = (
                result[column].astype("string").str.strip().str.lower()
                .replace("", pd.NA)
            )
    result["embarked"] = result["embarked"].fillna("unknown")
    return result


def prepare_analysis_data(frame):
    """Select the eight analysis fields, validate numeric values, and flag missing age."""
    columns = ["survived", "pclass", "sex", "age", "sibsp", "parch", "fare", "embarked"]
    result = frame.loc[:, columns].copy()
    for column in ["survived", "pclass", "age", "sibsp", "parch", "fare"]:
        original_missing = result[column].isna()
        result[column] = pd.to_numeric(result[column], errors="coerce")
        if (result[column].isna() & ~original_missing).any():
            raise ValueError(f"Invalid numeric values in {column}.")
    if not result["survived"].isin([0, 1]).all():
        raise ValueError("Survived must be coded 0 or 1.")
    if not result["pclass"].isin([1, 2, 3]).all():
        raise ValueError("Passenger class must be 1, 2, or 3.")
    if (result[["age", "sibsp", "parch", "fare"]] < 0).any().any():
        raise ValueError("Age, family counts, and fare cannot be negative.")
    result["age_missing"] = result["age"].isna()
    return result

5. Reusable exploratory analysis¶

The EDA function returns numerical summaries, group counts and observed survival rates, and an age-missingness comparison. Rates are descriptive proportions for these records, not causal effects or estimates for today's population. We use NumPy to independently check the overall proportion.

In [6]:
def summarize_passengers(frame):
    """Return numerical, class, sex-by-class, and age-missingness summaries."""
    numeric = frame[["age", "fare", "sibsp", "parch"]].describe()
    by_class = frame.groupby("pclass", observed=True)["survived"].agg(
        passengers="size", survivors="sum", survival_rate="mean"
    )
    by_sex_class = frame.groupby(["pclass", "sex"], observed=True)["survived"].agg(
        passengers="size", survivors="sum", survival_rate="mean"
    )
    by_age_missing = frame.groupby("age_missing", observed=True)["survived"].agg(
        passengers="size", survivors="sum", survival_rate="mean"
    )
    return {"numeric": numeric, "by_class": by_class,
            "by_sex_class": by_sex_class, "by_age_missing": by_age_missing}

10. Summary and interpretation¶

Recorded survival is higher in first class than in second or third class (Figure 2). The class totals are uneven, so comparing survivor counts alone would not answer the research question; the plotted rates use the displayed denominators. Within every class, the recorded female group has a higher observed survival proportion than the recorded male group (Figure 3). These descriptive differences do not demonstrate that sex or class alone caused survival.

The observed age distribution is concentrated in younger adulthood, but 177 ages are missing (Figure 1). The age-missingness table shows different observed survival proportions for records with and without ages, making a blanket complete-case analysis questionable. This is a warning, not proof of a specific missing-data mechanism. We preserved missing ages and retained these passengers in the survival summaries rather than silently narrowing the dataset.

An important data-quality finding is that 107 full-row attribute combinations repeat earlier records. Without passenger identifiers, these cannot be assumed to be erroneous duplicate people, so we did not remove them. The CSV includes redundant or derived fields, and the focused analysis selects eight original fields plus an age-missingness flag rather than treating every column as independent evidence.

Limitations include historical selection and recording practices, incomplete age information, the absence of passenger IDs, the restricted binary sex labels, and the fact that these 891 records are not a complete ship manifest. We cannot identify the reasons for missing ages or reconstruct omitted contextual factors. The workflow is a reproducible foundation for later AI work, not a trained model or a causal study. The report discusses further methodological safeguards and the use of agentic automation.
